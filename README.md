# Rudenko Design

Адаптивний сайт студії дизайну та виробництва меблів. Зроблений на HTML, CSS і JavaScript без збирача та зовнішніх бібліотек.

## Запуск

Сайт працює без сервера: відкрийте `index.html` у браузері. Каталог проєктів зберігається у `projects-data.js`. Оброблені WebP-версії фотографій розміщені в `Images/Enhanced`; вихідні файли збережено в початкових папках.

- Для розробки у VS Code можна запустити папку через розширення Live Server.

## Сторінки

- `index.html` — головна сторінка з горизонтальним слайдером із чотирма вкладками та семантичними `header`, `nav`, `main` і `footer`.
- `?page=about` — інформація про студію.
- `?page=projects` — усі роботи з фільтрами категорій.
- Кожна картка веде на власну галерею; приклад URL: `?page=project&category=Kitchens&project=Seasons`.
- `?page=contacts` — контактна інформація та форма звернення.

## Лабораторна робота №2

У `index.html` є HTML5 boilerplate, `lang="uk"`, кодування UTF-8, viewport, назва й опис сторінки, семантичні `header`, `nav`, `main` і `footer`, меню на основі `ul`/`li`, заголовки, абзаци та форматування `strong`/`em`. Головна містить чотири доступні горизонтальні слайди з керуванням стрілками, вкладками та клавіатурою. У стилях використано темну палітру та Montserrat легкої насиченості. Сторінка «Про нас» включає описи напрямів роботи, процесу та матеріалів і три запитання перед закликом до зустрічі. Дизайн адаптується до вузьких екранів.

Форма контактів відкриває нове звернення у поштовій програмі користувача. Для збереження заявок без поштової програми потрібно під’єднати поштовий сервіс або серверний endpoint.

## Контрольні запитання ЛР2

1. `<!DOCTYPE html>` повідомляє браузеру, що документ використовує сучасний стандарт HTML5.
2. `ul` створює маркований список, `ol` — нумерований; елементи обох списків розміщують у `li`.
3. На цій сторінці використовуємо один `h1` для головної теми. Подальші розділи мають `h2`, підрозділи — `h3`, що зберігає зрозумілу ієрархію для читачів і допоміжних технологій.
4. Парні теги мають відкривальний і закривальний тег, наприклад `<p>текст</p>` або `<strong>важливо</strong>`. Одиночний тег не має окремого закривального тега, наприклад `<br />` або `<hr />`.
5. Текст із `<title>` відображається у вкладці браузера та використовується як заголовок сторінки в результатах пошуку.
